# Travel Plan

Travel Plan is a Flutter-based mobile application designed to help users plan and organize their trips easily.

## Objective

To develop a simple and user-friendly travel planning application using Flutter and Dart.

## Technologies Used

- Flutter
- Dart

## Features

- Explore travel destinations
- View destination details
- Plan trips
- Manage travel budget
- Select trip duration

## Experiments

1. Flutter and Dart Basics
2. Flutter Widgets and Layouts
3. Responsive UI
4. Navigation
5. State Management
6. Custom Widgets and Themes
7. Forms and Validation
8. Animations
9. REST API Integration
10. Testing and Debugging
